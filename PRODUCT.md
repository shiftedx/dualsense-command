# Product

DSCC serves non-technical Windows gamers with DualSense or DualSense Edge,
especially racing players. First-session success: connect a controller, start a
supported game, feel effects, and understand output status. Setup requires no scripts.

| Moment | Task | Show first |
| --- | --- | --- |
| Setup | Connect and verify a controller. | Connection and output readiness. |
| Play | Select a game and tune feel. | Effective profile and game readiness. |

## Interface contract

Calm, trustworthy, capable; use plain [domain terms](CONTEXT.md) and explicit
hardware-action status. Borrow Linear's quiet dark hierarchy and Raycast's dense
settings. Avoid cockpit HUDs, RGB sales copy, glow/glass effects, all-caps
telemetry, and diagnostics-first navigation.

| Rule | Apply |
| --- | --- |
| Status before controls | Show readiness before editing. |
| Task-based navigation | Lead with controller setup and game tuning. |
| Advanced is opt-in | Put mapping, calibration, Edge slots and raw telemetry behind Advanced. |
| Visible safety | Distinguish Dry-Run Output, timed tests and live Hardware Output; separate Global and Game Profiles. |
| Consistent surfaces | Reuse components; one accent for state, selection and primary actions. |
| Accessible interaction | WCAG AA body contrast ≥4.5:1, keyboard navigation, `prefers-reduced-motion`; verify 390px layout with visual smoke. |
